Among Us Companion — مشروع Android أولي قابل للبناء

المميزات:
- لوحة تحكم عربية داكنة.
- محلل احتمال أساسي حسب عدد اللاعبين والمحتالين.
- سجل ملاحظات محلي للجلسة.
- يعمل دون اتصال ولا يطلب صلاحيات حساسة.

حدود التشغيل:
- لا يكشف مواقع اللاعبين الحقيقية ولا يقرأ بيانات اللعبة.
- لا يحتوي على حقن أو تعديل للعبة أو تجاوز لمكافحة الغش.
- لا توجد طريقة مضمونة لمنع الحظر عند استخدام أدوات غش؛ هذا المشروع لا يتصل باللعبة ولا يعدّلها.

البناء:
1. فك ضغط ZIP في AndroidIDE أو بيئة Android Gradle متوافقة.
2. افتح المجلد الذي يحتوي settings.gradle.kts.
3. نفّذ Gradle Sync.
4. اختر app ثم Run لبناء APK وتثبيته.

المتطلبات:
- Android Gradle Plugin 8.6.1
- Kotlin 2.0.20
- compileSdk 35
- minSdk 23

ملاحظة: لم يتم إجراء بناء فعلي داخل هذه الجلسة؛ يجب تنفيذ Gradle Sync/Build في بيئة Android للتحقق من توافق SDK المثبت.
